# Archeon Noctis R

Interactive 3D landing page built with Vite, Three.js, and GSAP.

## Project Structure

- `index.html`: page shell and content sections
- `assets/css/main.css`: visual system and layout
- `assets/js/`: app logic, scroll narrative, UI, and 3D scene setup
- `assets/models/car.glb`: optimized source model used by the scene

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Notes

- `dist/` is generated output and is intentionally ignored in git.
- `node_modules/` and local log files are intentionally ignored in git.
